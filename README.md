تطبيق نسخة طبق الأصل من Netflix مبني بـ Flutter مع دعم اللغتين العربية والإنجليزية.

## المميزات الرئيسية

### 🎬 المحتوى والعرض
- **تصميم مطابق لـ Netflix**: ألوان وأزرار وتصميم مطابق تماماً لـ Netflix الأصلي
- **عرض الأفلام والمسلسلات**: جلب البيانات من TMDB API
- **فئات متنوعة**: 
  - الأفلام الشائعة والرائجة
  - الأفلام الأعلى تقييماً والحديثة
  - المسلسلات الشائعة والرائجة
  - المسلسلات المعروضة حالياً

### 🔐 نظام المصادقة
- **تسجيل الدخول بـ Google**: مصادقة آمنة عبر Google
- **وضع الضيف**: إمكانية الدخول كضيف بكامل المزايا
- **بدون اشتراك**: التطبيق مجاني بالكامل

### 🌐 دعم اللغات
- **العربية**: اللغة الافتراضية مع دعم كامل للنصوص
- **الإنجليزية**: يمكن التبديل إليها من الإعدادات
- **جلب البيانات**: يتم جلب البيانات باللغة المحددة من TMDB

### 📱 مشغل الفيديو
- **تشغيل الأفلام**: عبر superembed.stream
- **واجهة مشغل متقدمة**: مع أدوات التحكم الكاملة
- **دعم الشاشة الكاملة**: للحصول على تجربة مشاهدة أفضل

### ⭐ المميزات الإضافية
- **المفضلة**: إضافة الأفلام والمسلسلات للمفضلة
- **تكملة المشاهدة**: حفظ موضع التوقف واستكمال المشاهدة
- **البحث المتقدم**: البحث في الأفلام والمسلسلات
- **سجل المشاهدة**: تتبع ما تم مشاهدته

## التقنيات المستخدمة

### Frontend
- **Flutter**: إطار العمل الرئيسي
- **Provider**: إدارة الحالة
- **Cached Network Image**: تحسين عرض الصور
- **WebView**: لتشغيل الفيديوهات

### Backend & APIs
- **Firebase**: 
  - Authentication (Google Sign-in)
  - Firestore (قاعدة البيانات)
  - Storage (تخزين البيانات)
- **TMDB API**: جلب بيانات الأفلام والمسلسلات
- **SuperEmbed.stream**: تشغيل الفيديوهات

## التثبيت والتشغيل

### المتطلبات
- Flutter SDK (3.0+)
- Android SDK
- Java JDK 17+

### خطوات التثبيت
1. **تثبيت المكتبات**:
   ```bash
   flutter pub get
   ```

2. **تشغيل التطبيق**:
   ```bash
   flutter run
   ```

### بناء APK
```bash
flutter build apk --release
```
